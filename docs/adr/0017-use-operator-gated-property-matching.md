# Use explainable, Operator-gated Property matching

TorobRent uses versioned deterministic measurements to create pairwise Property Match Suggestions
across Direct and External Listings, including cheap exact and perceptual image hashes but not
embeddings or model inference. Match Confidence helps Operators with Catalog Curation prioritize
and explain decisions, but the system never groups or separates Properties automatically and does
not delay otherwise valid Listing publication; this favors auditability, reversibility, privacy,
and predictable operating cost over fully automated identity resolution.
