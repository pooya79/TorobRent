# Use React Router Framework Mode for public-page rendering

TorobRent migrates its thin Vite SPA shell to React Router Framework Mode, using runtime server
rendering for public Property pages and pre-rendering for static public pages. Organic discovery is
a strategic acquisition channel, so accepting a client-only foundation would force a costly
migration before public beta; this approach preserves React Router and keeps Django as the domain
API while adding a frontend runtime behind nginx.
