# Use verified email or phone for account access

TorobRent accounts may authenticate with either a verified email address and password or a verified
mobile number and password; an identifier cannot be used for login until its verification succeeds,
and both verified identifiers may belong to the same account. Starting the Submitter journey
additionally requires a verified mobile number, even when the account already has a verified email.
This keeps account access flexible while requiring a reachable phone before a person can propose
public rental information.
