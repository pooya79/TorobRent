# Separate communication records behind one Message Center

TorobRent will present Listing Inquiries, Support Requests, and System Notifications together in
one Message Center, but each remains a distinct record with its own participants, lifecycle, and
authorization rules. A single generic conversation model would obscure Support privacy and
workflow controls, make non-replyable notifications behave like conversations, and lose the exact
Listing boundary required for renter-to-Submitter contact.
