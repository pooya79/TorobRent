# Assign each external Source to one representative

TorobRent gives each external Source one exclusive, Operator-approved Source Assignment rather
than allowing several Submitters to extract from the same domain independently. The assignment is
revocable and does not assert legal ownership; revocation stops new extraction, deactivates the
Source Profile, withdraws Listings produced through the assignment, and preserves the audit
history. This keeps responsibility and per-user monitoring unambiguous while allowing an Operator
to correct or reassign a mistaken approval.
