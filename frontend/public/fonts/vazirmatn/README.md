# Vazirmatn

Unmodified variable WOFF2 font from [Vazirmatn v33.003](https://github.com/rastikerdar/vazirmatn/tree/v33.003).

Source: `fonts/webfonts/Vazirmatn[wght].woff2`. Supports weights 100–900.
Distributed under the SIL Open Font License 1.1; see `OFL.txt`.
Served locally so visitors do not need access to a third-party font service.
